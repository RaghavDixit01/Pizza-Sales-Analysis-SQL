# 🍕 Pizza Sales Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing pizza sales data using **SQL** to extract meaningful business insights.  
The analysis answers key questions related to revenue, customer preferences, order trends, and product performance.

The dataset used is **pre-designed** and was imported from CSV files.  
My role in this project was **data analysis and query writing**, not database design.

---

## 🎯 Objectives
- Analyze total orders and total revenue
- Identify most popular pizzas and sizes
- Understand customer ordering patterns
- Perform category-wise and revenue-based analysis
- Apply basic to advanced SQL concepts on real data

---

## 🗂️ Dataset Information
- **Source:** Pizza Sales Dataset (Kaggle)
- **Data Format:** CSV files
- **Tables Used:**
  - `orders`
  - `order_details`
  - `pizzas`
  - `pizza_types`

> Note: Tables were directly imported into MySQL from CSV files.

---

## 🗄️ Database Schema
The database schema is documented in the `schema.sql` file.  
It contains the structure of all tables, including column names and data types.
